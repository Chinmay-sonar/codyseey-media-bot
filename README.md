# Codyseey Media Bot 🚀

Autonomous 24/7 Telegram Media Extractor Bot.
Extracts maximum resolution images and videos from ANY webpage and delivers them as pure photo albums directly to Telegram.

## Features
- **24/7 Cloud Uptime:** Zero dependency on local PC, Docker, or desktop apps.
- **Universal Multi-CMS Support:** Upgrades Drupal, WordPress, Shopify, Squarespace, Webflow (`.avif` -> `.jpg`), and Next.js to highest uncompressed resolution.
- **Pure Media Delivery:** Clean photo albums (up to 10 photos per album), 0 annoying text spam.
- **Built-in Healthcheck:** Includes HTTP server for cloud platforms (Render, Railway, Koyeb).

## Deployment on Render.com
1. Create a new **Web Service** on [Render.com](https://render.com).
2. Connect your repository: `Chinmay-sonar/codyseey-media-bot`.
3. Runtime: **Node**.
4. Build Command: (leave empty or `npm install`)
5. Start Command: `node index.js`
6. Click **Deploy Web Service**.
